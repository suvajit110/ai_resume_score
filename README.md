# AI Resume Score

AI Resume Score is a MERN stack web application that analyzes resumes and provides resume scoring and feedback using AI.

## Features

- User Authentication
- Resume Upload
- AI Resume Analysis
- Resume Score Generation
- Admin Dashboard
- Protected Routes
- MongoDB Database Integration

## Tech Stack

### Frontend
- React.js
- Vite
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
